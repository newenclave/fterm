# The language of fterm

fterm can show its UI in your language: the command palette, toasts, questions, the dock, the Review tab,
the AI panel, the history lists, and the window title. English is built in. Another language is a JSON file
that you put next to your config.

## Choose a language
In `fterm.lua`:

```lua
language = "ru",          -- the file l10n/ru.json
language = "system",      -- the language of the system, if there is a file for it (else English)
language = "C:/my/ru.json", -- a file anywhere
```

No `language`, or `language = "en"` = English. fterm changes the language at once when you save `fterm.lua`
or a file in the `l10n` folder.

fterm looks for `<code>.json` in a folder `l10n` next to `fterm.lua`, then in `l10n` in your `data_dir`.
For a code with a region (`ru-RU`, from `"system"`), it tries `ru-RU.json` and then `ru.json`.

## Make a language file
1. Take `l10n/en.json` from the fterm archive (or [assets/l10n/en.json](../assets/l10n/en.json) in the repository).
2. Copy it to `l10n/ru.json` (use your language code) next to `fterm.lua`.
3. Change `language` and `name`, and translate the texts. Keep the keys on the left as they are.
4. Put `language = "ru"` into `fterm.lua`.

```json
{
  "language": "ru",
  "name": "Русский",
  "strings": {
    "action.new_tab": "Новая вкладка",
    "toast.config_reloaded": "Конфиг перечитан",
    "count.tabs": { "one": "{n} вкладка", "few": "{n} вкладки", "many": "{n} вкладок" }
  }
}
```

You do not need all keys. A key that is not in your file stays English. So you can start with a few texts.

### Rules
- **`{name}`** is a value that fterm puts in, for example `{path}` or `{tab}`. Keep it, but you can move it in
  the sentence. Text in `{ }` with spaces (Lua in a hint, like `{ enabled = true }`) is plain text.
- **Plural forms.** Some texts are lists of forms, because they have a number `{n}`:
  `one`, `few`, `many`, `other` (also `zero` and `two`). fterm picks the form by the rules of your language:
  English uses `one` and `other`; Russian, Ukrainian, and Belarusian use `one`, `few`, and `many`; Polish
  uses `one`, `few`, and `many`; Czech and Slovak use `one`, `few`, and `other`; Japanese, Chinese, and
  Korean use only `other`. A missing form uses `other`.
- **Key names stay.** Hints like `Enter = close, Esc = cancel` name keys of the keyboard. The keys do not
  change with the language, so keep `Enter`, `Esc`, `Ctrl+G`, and the letters (`R`, `S`, `C`, ...).

### When something is wrong
- A file with bad JSON, or that fterm cannot read: the language does not change, and a "Language error"
  toast says why.
- A key that English does not have, a text where English has plural forms (or the other way), or a `{name}`
  that English does not have: fterm uses the file, and a toast lists the problems.

## What stays English
- Errors in `fterm.lua` and in themes (they name Lua keys).
- `ftermctl`, the MCP tools, and the API: scripts and agents read them.
- What fterm sends to agents and AI models (the feedback of a review, the prompts).
- Error texts from AI providers.

Notification titles are translated. If your Lua `on_notification` or a script that reads the `notification`
event checks a title, check it in your language.
